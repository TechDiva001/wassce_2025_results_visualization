# 📊 WASSCE 2025 Results Visualization

## 🌟 Project Overview
This project analyzes and visualizes the 2025 West African Senior School Certificate Examination (WASSCE) results using data visualization techniques. The analysis reveals key insights about student performance, trends over time, and examination irregularities.

## 🎯 Business Problem
Education stakeholders need clear insights into student performance trends and examination integrity. Raw exam results data in tables is difficult to interpret. This project transforms complex data into actionable visual insights for policymakers, school administrators, and the public.

## 📊 Project Files
## wassce_visualization.ipynb

Notebook Overview: Complete data visualization project analyzing WASSCE 2025 results using Python visualization libraries.

**Project Structure**:

1. Data Preparation - Creating DataFrames from WAEC report data
2. Visualization 1 - 2025 Subject Performance Comparison (Bar Chart)
3. Visualization 2 - 4-Year Performance Trends (Line Chart)
4. Visualization 3 - Grade Distribution Analysis (Heatmap)
5. Visualization 4 - Examination Irregularities (Bar Chart)
6. Visualization 5 - Candidate Gender Distribution (Bar Chart)
7. Visualization 6 - Subject Relationships (Scatter Plot with Regression)
8.Summary Statistics - Key findings and insights

**Key Features**:

1. 6 different visualization types using only Kaggle-learned techniques
2. Professional chart styling and customization
3. Clear data storytelling with annotations
4. Complete analysis from raw data to insights
5. Real-world education data application

## 📈 Data Sources
Data extracted from official WAEC press release "Release of Provisional Results for the West African Senior School Certificate Examination (WASSCE) for School Candidates, 2025" dated November 29, 2025.
